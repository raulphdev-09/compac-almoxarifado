# Modelos de comparação facial experimental

Arquivos obtidos do OpenCV Zoo, revisão `48b10fa505aeb51fbd127fc60a5c660040e823b7`:

- [YuNet — MIT](YuNet-MIT.txt), [fonte oficial](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_detection_yunet).
- [SFace — Apache 2.0](SFace-Apache-2.0.txt), [fonte oficial](https://github.com/opencv/opencv_zoo/tree/48b10fa505aeb51fbd127fc60a5c660040e823b7/models/face_recognition_sface).

O pacote `opencv-python-headless` e o OpenCV correspondente usam Apache 2.0; a distribuição contém avisos de terceiros próprios. A instalação mantém os avisos dos modelos junto dos pesos privados. Os pesos não são incluídos no repositório; seu download explícito confere SHA-256 e tamanho fixados em `app/attendance/face_engine.py`.
